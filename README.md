## Overview

**Green Bank** is a responsive fintech web application engineered to showcase a modern digital banking experience. Built with performance, trust, and visual polish in mind, the interface guides visitors through key value propositions, security highlights, credit card benefits, and social proof to drive user acquisition.

🔗 **Live Preview:** [green-bank-pied.vercel.app](https://green-bank-pied.vercel.app/)

---

## Key Features

- **Mobile-First Responsive Design:** Fluid layouts adapted across mobile, tablet, and desktop viewports.
- **Conversion-Oriented UI:** Strategic placement of Call-to-Actions (CTAs), value propositions, and feature breakdowns.
- **Trust & Security Highlights:** Dedicated sections emphasizing financial protection, transparency, and modern banking standards.
- **Social Proof & Testimonials:** Customer feedback integration to build credibility and user confidence.
- **Optimized Performance:** Built on Next.js App Router with fast asset loading and modern React architecture.

## Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

- **Node.js** (v20 or higher recommended)
- **npm**, **yarn**, **pnpm**, or **bun**

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/seu-usuario/green-bank.git](https://github.com/seu-usuario/green-bank.git)
   cd green-bank
   ```
