Green Bank is a modern fintech landing page built with Next.js, React, and Tailwind CSS. The project presents a polished, responsive, and conversion-focused homepage for a digital banking and credit card brand.

It highlights trust, product value, financial security, customer testimonials, and a strong mobile-first user experience designed to attract and convert visitors.
