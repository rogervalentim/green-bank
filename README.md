## About the project

Green Bank is a modern landing page for a digital bank, created to showcase competitive advantages, security, card benefits, and social proof in a clear and persuasive way. The goal is to deliver a premium, responsive visual experience optimized to generate interest, trust, and conversion.

## Key features

- Responsive layout for mobile, tablet, and desktop
- Conversion-focused UI with strategic CTAs
- Sections for benefits, security, cards, and testimonials
- Premium visual design centered on trust and credibility
- Optimized performance with Next.js and React
- Clean, maintainable structure for easy evolution

## Requirements

Before starting, make sure you have installed:

- Node.js 20 or higher
- npm (or pnpm, yarn, or bun)

## Running locally

### 1) Clone the repository

```bash
git clone https://github.com/rogervalentim/green-bank.git
cd green-bank
```

### 2) Install dependencies

```bash
npm install
```

### 3) Start the development server

```bash
npm run dev
```

The application will be available at:

```bash
http://localhost:3000
```

## Available scripts

```bash
npm run dev     # starts the app in development mode
npm run build   # builds the production version
npm run start   # starts the production app
npm run lint    # runs static analysis for the project
```

## Notes

This project was developed as an institutional landing page for presenting a digital bank. It is ready for local use, visual customization, and future integration with real marketing, authentication, or signup flows.
